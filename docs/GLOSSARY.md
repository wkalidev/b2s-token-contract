# Glossary

## AMM
Automated Market Maker — algorithm for token swaps

## APY
Annual Percentage Yield — yearly return rate

## Basis Points
1 bps = 0.01% — used for fee calculation

## Clarity
Smart contract language for Stacks blockchain

## LP Token
Liquidity Provider token — represents pool share

## SIP-009
Stacks Improvement Proposal for NFT standard

## SIP-010
Stacks Improvement Proposal for fungible token standard

## STX
Native token of the Stacks blockchain

## sBTC
Bitcoin bridged to Stacks blockchain
