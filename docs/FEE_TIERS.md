# Fee Tiers

## Bridge Fee Router
Volume-based fee tiers via b2s-fee-router:

| Volume       | Fee   |
|-------------|-------|
| < 100 B2S   | 0.30% |
| 100-1000 B2S | 0.25% |
| > 1000 B2S  | 0.20% |

## Liquidity Pool
Flat 0.25% fee on all swaps.
100% goes to LP providers.

## NFT Marketplace
2.5% platform fee on all sales.
97.5% goes to seller.
