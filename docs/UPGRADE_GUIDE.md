# Contract Upgrade Guide

## Why versioning?
Clarity contracts are immutable once deployed.
New versions = new contract names (v2, v3...).

## Migration steps
1. Deploy new contract version
2. Migrate state if needed
3. Update frontend to new address
4. Announce upgrade to users
