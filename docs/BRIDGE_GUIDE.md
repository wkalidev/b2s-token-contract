# Bridge Guide

## Supported Bridges
- deBridge: https://app.debridge.com/r/32893
- Rango Exchange: https://rango.vip/a/o9pwCm
- Stargate Finance

## How to bridge Base → Stacks
1. Connect wallet on bridge platform
2. Select Base as source chain
3. Select Stacks as destination
4. Enter amount and confirm
