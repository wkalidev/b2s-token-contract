# Security Tips for Users

## Wallet Security
- Never share your seed phrase
- Use hardware wallet for large amounts
- Verify contract address before signing

## Transaction Safety
- Check function name before confirming
- Set reasonable slippage tolerance (0.5-2%)
- Start with small amounts when testing

## Smart Contract Safety
- All contracts are immutable on Stacks
- Admin functions require contract-owner
- No rugpull mechanism exists
